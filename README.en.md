# Technical Indicators Analysis
Analyze stock daily and weekly K-line data via technical indicators to assist personal trading decisions.

> ⚠️ **Disclaimer**: All calculations and outputs of this project are for personal research and study only. **This is NOT investment advice**. Trading in securities involves high risks.

## About This Project
This project computes mainstream technical indicators from K-line data and detects trading signals. It helps observe price trends on daily and weekly timeframes for your own reference when making trading decisions.

## Supported Indicators
- MACD (Golden cross / Death cross detection)
- RSI
- SAR
- Bollinger Bands
- Moving Average (MA)

## Roadmap
- Load daily & weekly K-line data
- Calculate technical indicators listed above
- Detect indicator signals and generate analysis reports
- Visualization of indicators (planned)
