# Technical Indicators Analysis
基于技术指标对股票日线、周线K线进行分析，辅助个人交易决策。

> ⚠️ **风险提示**：本项目所有工具、指标计算结果仅作为个人学习研究参考，**不构成任何投资建议**。股市有风险，投资需谨慎。

## 📌 项目简介
本项目实现常见技术指标的计算与行情分析，读取K线数据，自动识别信号，用于辅助观察标的日线、周线级别走势，为个人买卖决策提供参考。

## ✅ 支持指标
- MACD（金叉 / 死叉识别）
- RSI（超买 / 超卖）
- SAR（翻红 / 翻绿）
- 布林线（上中下轨）
- 均线（多头排列 / 空头排列）
- 顶背离 / 底背离
- 九转序列
- 一阳穿多均，断头铡刀

## 📋 功能规划
- 读取标的日K、周K行情数据
- 计算上述技术指标
- 识别指标信号、输出分析结果
- 指标可视化（后续迭代）
